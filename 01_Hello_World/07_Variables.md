# Variables

## 1. What is it?

A variable is a named place where a program stores a value. Declare it with a type, a name and optionally a starting value.

## 2. Basic syntax

```csharp
string name = "Alex";
int age = 25;

Console.WriteLine(name);
Console.WriteLine(age);
```

## 3. Line-by-line explanation

- `string` is used for text.
- `int` is used for whole numbers.
- `=` assigns a value to a variable.
- A variable's value can be changed later unless it is a constant.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
