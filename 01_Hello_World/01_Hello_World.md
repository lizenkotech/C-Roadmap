# Hello World

## 1. What is it?

A first C# program can display a message in the console. This is a simple way to check that your program runs.

## 2. Basic syntax

```csharp
Console.WriteLine("Hello, World!");
```

## 3. Line-by-line explanation

- `Console` provides console input and output.
- `WriteLine` displays text and then moves to the next line.
- Text is placed between double quotation marks.
- The semicolon ends the statement.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
