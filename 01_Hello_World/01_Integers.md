# Integers

## 1. What is it?

An integer is a whole number. It does not contain a decimal part.

In C#, the `int` data type is commonly used to store whole numbers.

Examples:

- 10
- 25
- -5
- 0

## 2. Basic syntax

```csharp
int age = 27;
int numberOfStudents = 18;

Console.WriteLine(age);
Console.WriteLine(numberOfStudents);
```

## 3. Line-by-line explanation

- `int` defines the variable as an integer.
- `age` is the name of the variable.
- `=` assigns a value to the variable.
- `27` is the value stored in the variable.
- `Console.WriteLine()` displays the value.

## 4. Important notes

- An `int` stores whole numbers.
- An `int` can contain positive numbers, negative numbers and zero.
- An `int` cannot store decimal numbers.
- The range of an `int` is -2,147,483,648 to 2,147,483,647.
