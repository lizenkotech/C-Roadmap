# Console.Write

## 1. What is it?

`Console.Write()` displays text or a value but keeps the cursor on the same line.

## 2. Basic syntax

```csharp
Console.Write("Hello ");
Console.Write("there!");
Console.WriteLine();
Console.WriteLine("This is a new line.");
```

## 3. Line-by-line explanation

- `Console.Write()` continues on the current line.
- `Console.WriteLine()` moves to the next line after printing.
- You can combine both methods.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
