# Multi-Line Comments

## 1. What is it?

A multi-line comment can cover several lines. It starts with `/*` and ends with `*/`.

## 2. Basic syntax

```csharp
/*
This program displays
a short welcome message.
*/
Console.WriteLine("Welcome!");
```

## 3. Line-by-line explanation

- `/*` marks the beginning of a multi-line comment.
- `*/` marks the end.
- C# ignores everything between these markers.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
