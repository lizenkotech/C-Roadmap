# Single-Line Comments

## 1. What is it?

A comment is text in your code that C# ignores when the program runs. A single-line comment starts with `//`.

## 2. Basic syntax

```csharp
// Display a welcome message.
Console.WriteLine("Welcome to C#!");

// Display the year.
Console.WriteLine(2026);
```

## 3. Line-by-line explanation

- Write `//` to start a single-line comment.
- The comment continues to the end of that line.
- Comments explain code and do not change the program output.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
