# Console Printing with WriteLine

## 1. What is it?

`Console.WriteLine()` displays text or a value and then moves to the next line.

## 2. Basic syntax

```csharp
Console.WriteLine("Welcome!");
Console.WriteLine("I am learning C#.");
Console.WriteLine(2026);
```

## 3. Line-by-line explanation

- Each call displays one item.
- Text uses double quotation marks; numbers do not need them.
- Each call to `WriteLine` starts the next output on a new line.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
