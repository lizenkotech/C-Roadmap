# Doubles

## 1. What is it?

A `double` is a data type used to store numbers with decimal places.

Examples:

- 3.14
- 10.5
- -2.75
- 0.25

A `double` can store numbers with a fractional part.

## 2. Basic syntax

```csharp
double price = 19.99;
double temperature = 22.5;

Console.WriteLine(price);
Console.WriteLine(temperature);
```

## 3. Line-by-line explanation

- `double` declares a variable that can store decimal numbers.
- `price` is the name of the variable.
- `=` assigns a value to the variable.
- `19.99` is the value stored in the variable.
- `Console.WriteLine()` displays the value.

## 4. Important notes

- A `double` can store decimal numbers.
- A `double` uses approximately 15–16 significant digits of precision.
- Decimal values written as literals are treated as `double` by default in C#.
- A `double` is useful for many general calculations involving decimal numbers.
