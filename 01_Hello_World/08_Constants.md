# Constants

## 1. What is it?

A constant is a value that is set once and cannot be changed while the program runs. Use the `const` keyword.

## 2. Basic syntax

```csharp
const double Pi = 3.14159;
Console.WriteLine(Pi);
```

## 3. Line-by-line explanation

- `const` declares a constant.
- A constant must receive its value when declared.
- You cannot assign a new value to it later.
- Use constants for values that should not change.

## 4. Important notes

- C# statements usually end with a semicolon (`;`).
- C# is case-sensitive: `WriteLine` and `writeline` are different.
- Use clear names to make code easier to understand.
