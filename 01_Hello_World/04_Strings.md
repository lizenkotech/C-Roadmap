# Strings

## 1. What is it?

A string is a sequence of characters used to store text.

Examples:

- "Hello"
- "Alice"
- "Welcome to C#"

## 2. Basic syntax

```csharp
string firstName = "Alice";
string message = "Hello, world!";

Console.WriteLine(firstName);
Console.WriteLine(message);
```

## 3. Line-by-line explanation

- `string` declares a text variable.
- `firstName` is the variable name.
- `"Alice"` is the text stored in the variable.
- Text values are written between double quotation marks.
- `Console.WriteLine()` displays the text.

## 4. Important notes

- A string stores text.
- Strings use double quotation marks.
- A string can contain letters, numbers and symbols.
- An empty string can be written as `""`.
