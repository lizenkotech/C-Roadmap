# Floats

## 1. What is it?

A `float` is a data type used to store numbers with decimal places.

It is similar to `double`, but it has less precision and uses less memory.

## 2. Basic syntax

```csharp
float temperature = 21.5f;
float speed = 60.5f;

Console.WriteLine(temperature);
Console.WriteLine(speed);
```

## 3. Line-by-line explanation

- `float` declares a variable that stores a floating-point number.
- `temperature` is the variable name.
- `21.5f` is the assigned value.
- The letter `f` tells C# that the number is a float literal.
- `Console.WriteLine()` displays the value.

## 4. Important notes

- A `float` can store decimal numbers.
- A float literal needs the suffix `f` or `F`.
- A `float` uses 32 bits of memory.
- A `double` uses 64 bits and has more precision.
- A `float` is useful when memory usage is important.
