# Chars

## 1. What is it?

A `char` stores one single character.

Examples:

- 'A'
- 'B'
- '7'
- '?'

## 2. Basic syntax

```csharp
char grade = 'A';
char symbol = '?';

Console.WriteLine(grade);
Console.WriteLine(symbol);
```

## 3. Line-by-line explanation

- `char` declares a character variable.
- `grade` is the variable name.
- `'A'` is the character stored in the variable.
- Character values use single quotation marks.
- `Console.WriteLine()` displays the character.

## 4. Important notes

- A `char` stores one character.
- A `char` uses single quotation marks.
- A `string` uses double quotation marks.
- A `char` can contain a letter, digit or symbol.
