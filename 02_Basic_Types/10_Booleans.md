# Booleans

## 1. What is it?

A Boolean is a data type that stores one of two values:

- `true`
- `false`

Booleans are often used to check conditions and make decisions in a program.

## 2. Basic syntax

```csharp
bool isStudent = true;
bool isFinished = false;

Console.WriteLine(isStudent);
Console.WriteLine(isFinished);
```

## 3. Line-by-line explanation

- `bool` declares a Boolean variable.
- `isStudent` is the variable name.
- `true` means the condition is true.
- `false` means the condition is false.
- `Console.WriteLine()` displays the values.

## 4. Important notes

- A Boolean can only contain `true` or `false`.
- Boolean values do not use quotation marks.
- Booleans are often used with `if` statements.
- Comparisons can produce Boolean results.
